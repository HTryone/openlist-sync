过滤规则 · .nosy

在本地文件夹根目录写入 .nosy，按 gitignore 语法排除不想同步的文件。每行一条，# 开头为注释，! 开头为白名单（例外）。留空并保存＝删除该文件（同步全部）。
示例：node_modules/ 排除任意层级的 node_modules；docs/* 只排除根下 docs；*.log 排除所有 .log；.env 排除所有 .env
