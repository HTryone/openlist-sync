# 验证清单

> 上传/上线前，**先在测试目录**跑一遍，确认行为符合预期再指向正式目录。

## 约定（两端一致）

```
本地工作区            →   openlist:/ty2/agents-sy/<文件夹名>
删除归档（远端）       →   openlist:/ty2/agents-sy/.trash/<文件夹名>/
```

- 垃圾桶在同步目标**之外**（各自独立），不参与同步、不被二次清理
- 比较方式 **size-only**

---

## 方式 A：Windows 桌面端（ui/）

用面板操作最直观，逐项核对：

| # | 操作 | 预期结果 |
|---|---|---|
| 1 | 选本地文件夹 → 自动派生网盘目标 | 目标 = `agents-sy/<文件夹名>`，且网盘目录已建好 |
| 2 | 点「首次同步」 | 本地文件出现在 `openlist:/ty2/agents-sy/<名>/` |
| 3 | 修改本地文件（大小变化）→「同步」 | 远端同文件更新 |
| 4 | 本地**新建**文件 →「同步」 | 远端出现 |
| 5 | 本地**删除**文件 →「同步」 | 远端消失，出现在 `agents-sy/.trash/<名>/` |
| 6 | 再「同步」一次 | 垃圾桶里的文件**仍在**（不被二次清理） |
| 7 | 远端新增文件（别的 Agent 上传）→「同步」 | 本地出现，可直接读 |
| 8 | 看本地文件夹 | **没有**任何 trash 目录；日志无 `aborted`/`ERROR` |

附加（冲突、安全阀）：

| # | 操作 | 预期结果 |
|---|---|---|
| 9 | 同一文件两端改不同内容 →「同步」 | 两侧出现 `xxx.conflict1` / `xxx.conflict2`，内容都保留 |
| 10 | 极小目录里改了唯一文件 →「同步」 | 可能报 `Safety abort: all files were changed`（保护，非 bug） |
| 11 | 网盘上删掉一个本地也有的文件 →「同步」 | 本地文件消失，但**出现在系统回收站**，右键可「还原」回原文件夹 |
| 12 | 把本地目录放到 U 盘 / FAT32 盘，重复 #11 | 文件落到程序目录 `trash\<任务ID>\<时间戳>\`，日志提示「留档」，不会直接删掉 |

## 方式 B：Linux 服务器端（deploy/）

```bash
# 前置：已按 deploy/install-linux-systemd.sh 部署，WORKSPACE=/work/workspace，远端 openlist:/ty2/agents-sy/workspace

# 2. 本地新增
echo hi > /work/workspace/test1.md
/usr/local/bin/openlist-bisync.sh sync
rclone lsf openlist:/ty2/agents-sy/workspace/           # 应看到 test1.md

# 4. 本地删除 → 归档
rm /work/workspace/test1.md
/usr/local/bin/openlist-bisync.sh sync
rclone lsf openlist:/ty2/agents-sy/workspace/           # 应无 test1.md
rclone lsf openlist:/ty2/agents-sy/.trash/workspace/    # 应看到 test1.md

# 5. 再同步，确认垃圾桶不被清
/usr/local/bin/openlist-bisync.sh sync
rclone lsf openlist:/ty2/agents-sy/.trash/workspace/    # test1.md 仍在

# 8. 干净性检查
find /work/workspace -iname '*trash*'                   # 应无输出（垃圾桶在同步源之外）
grep -iE 'error|aborted' /var/log/openlist-bisync.log   # 应无 ERROR/aborted
```

## 失败排查

| 现象 | 原因 / 处理 |
|---|---|
| `cannot find prior Path1 or Path2 listings` | 状态目录被清或上次中断；跑一次 `--resync` 重建 |
| `must run --resync` | 上次中断；`--recover` 会自动救，仍失败则 `--resync` |
| `Safety abort: all files were changed` | 数据量太小或真被清空；核对后用 `--force` 或从 `.trash` 恢复 |
| `mustn't overlap` | 垃圾桶放进了目标内；移到目标之外（本方案用 `.trash` 同级兄弟目录） |
| 大小不变仅改内容未同步 | size-only 的固有局限；见 `弱网调参.md` |
