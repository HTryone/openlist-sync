## 逐条命令参考（Linux，远端用 openlist:）

```bash
# 2. 本地新增
echo hi > /work/workspace/docs/test1.md
/usr/local/bin/openlist-bisync.sh sync
rclone lsf openlist:/backup/workspace/docs/            # 应看到 test1.md

# 3. 本地修改
echo hi2 > /work/workspace/docs/test1.md
/usr/local/bin/openlist-bisync.sh sync
rclone cat openlist:/backup/workspace/docs/test1.md    # 应为 hi2

# 4. 本地删除
rm /work/workspace/docs/test1.md
/usr/local/bin/openlist-bisync.sh sync
rclone lsf openlist:/backup/workspace/docs/            # 应无 test1.md
rclone lsf openlist:/trash/workspace/docs/             # 应看到 test1.md

# 5. 再同步，确认垃圾桶不被清
/usr/local/bin/openlist-bisync.sh sync
rclone lsf openlist:/trash/workspace/docs/             # test1.md 仍在

# 6. 远端新增（模拟别的 Agent 上传）
echo from-agent | rclone rcat openlist:/backup/workspace/shared/from-agent.md
/usr/local/bin/openlist-bisync.sh sync
cat /work/workspace/shared/from-agent.md               # 本地可见

# 7. 远端删除
rclone delete openlist:/backup/workspace/shared/from-agent.md
/usr/local/bin/openlist-bisync.sh sync
ls /work/workspace/shared/from-agent.md                # 应不存在
ls /work/_trash_local/shared/from-agent.md             # 本地垃圾桶里有

# 8. 干净性检查
find /work/workspace -iname '*trash*'                  # 应无输出
grep -iE 'error|aborted' /var/log/openlist-bisync.log  # 应无 ERROR/aborted
```

## 失败排查

| 现象 | 原因 / 处理 |
|---|---|
| `cannot find prior Path1 or Path2 listings` | 状态目录被清或上次中断；跑一次 `--resync` 重建 |
| `must run --resync` | 上次中断；`--recover` 会自动救，仍失败则 `--resync` |
| `Safety abort: all files were changed` | 数据量太小或真被清空；核对后 `--force` 或 `/trash` 恢复 |
| `mustn't overlap` | `/trash` 放进了目标内；挪到与目标同级 |
| checksum 不生效 | WebDAV 未暴露哈希；见 `弱网调参.md` 的自查与降级 |
